PrivFed: Privacy-Preserving Federated Learning for Fraud Detection
==================================================================
Complete Setup and Installation Instructions

SYSTEM REQUIREMENTS
==================
- Python 3.10 or higher
- Flutter 3.10 or higher  
- Git 2.30 or higher
- 8GB+ RAM (16GB recommended)
- 50GB+ free disk space
- CUDA-capable GPU (optional, for faster training)

TRAINING PIPELINE SETUP
=======================

1. Run Centralized Baseline:
   cd backend
   python scripts/run_centralized_baseline.py
   
   # With custom parameters:
   python scripts/run_centralized_baseline.py --epochs 20 --batch-size 256

2. Run Federated Learning:
   python scripts/run_federated_training.py
   
   # With custom rounds:
   python scripts/run_federated_training.py --rounds 30

3. Run Federated Learning with Differential Privacy:
   python scripts/run_federated_dp_training.py --epsilon 8.0
   
   # Different privacy levels:
   python scripts/run_federated_dp_training.py --epsilon 4.0
   python scripts/run_federated_dp_training.py --epsilon 2.0

4. View Results:
   # Results will be saved in:
   backend/results/
   ├── centralized_baseline_results.json
   ├── federated_results.json
   ├── federated_dp_results.json
   ├── training_history.csv
   ├── confusion_matrix.png
   ├── roc_curve.png
   └── privacy_vs_accuracy.png

DOCKER DEPLOYMENT (Optional)
============================

   cd backend
   docker build -t privfed-backend .

2. Run Backend Container:
   docker run -p 8000:8000 -v $(pwd)/dataset:/app/dataset privfed-backend

3. Docker Compose (Full Stack):
   cd ..

   # Services will be available at:

PRODUCTION DEPLOYMENT
====================

BACKEND PRODUCTION:
1. Set Environment Variables:
   export ENVIRONMENT=production
   export DATABASE_URL=postgresql://user:pass@localhost/privfed
   export SECRET_KEY=your-secret-key-here

2. Install Production Dependencies:
   pip install gunicorn

3. Run with Gunicorn:
   gunicorn api.main:app -w 4 -k uvicorn.workers.UvicornWorker

TROUBLESHOOTING
===============

COMMON ISSUES:

1. "Dataset files not found":
   - Verify dataset files exist at specified paths
   - Check file permissions
   - Update config.yaml with correct paths

2. "CUDA out of memory":
   - Reduce batch size in config.yaml
   - Use CPU training: set device: "cpu" in config
   - Close other GPU-intensive applications

3. "Flutter doctor issues":
   - Run: flutter doctor --verbose
   - Follow specific instructions for your platform
   - Ensure all licenses are accepted

4. "API connection failed" (Mobile):
   - Verify backend is running: curl http://localhost:8000/api/status
   - Check firewall settings
   - Use correct IP address for physical devices

5. "Import errors" (Python):
   - Verify virtual environment is activated
   - Reinstall requirements: pip install -r requirements.txt --force-reinstall
   - Check Python version: python --version

6. "Permission denied" errors:
   - Check file/directory permissions
   - Run with appropriate user privileges
   - Verify write access to results directories

PERFORMANCE OPTIMIZATION:

1. Backend Performance:
   - Use GPU for training: CUDA_VISIBLE_DEVICES=0
   - Increase worker processes for production
   - Enable caching for API responses
   - Use connection pooling for database

2. Mobile Performance:
   - Build in release mode for testing
   - Enable R8/ProGuard for Android
   - Optimize images and assets
   - Use const constructors where possible

3. Training Performance:
   - Use mixed precision training
   - Optimize batch sizes for your hardware
   - Use data loading optimizations
   - Profile code to identify bottlenecks
